言代Kotoshiro 0.9.10 — 透明线条标题标志

适用：Windows 10 / 11，64 位电脑。语音识别可选择本地或 API；识别服务与文字翻译服务分别设置。
本地模式在本机识别音频；API 模式会上传短音频给用户选择的识别服务。翻译服务只处理识别后的文字。
这是可试用的原型。本版已验证实际 Windows 窗口与模拟语音 API；尚未用真实语音 API 密钥测试服务端识别质量、费用和耗时。不同配置电脑与长时间直播仍需要实测。

首次使用
程序文件、任务栏与应用窗口使用白底黑线的白色版图标。主窗口顶部“言代Kotoshiro”文字后显示透明的主体线条：白色主题用黑线，黑色主题用白线，不带方形底板。
主窗口左侧分为“实时翻译”“延时翻译”“翻译记录”，底部另有“设置”。
实时翻译：选择电脑正在播放直播声音的设备，点击“开始翻译”。
延时翻译：输入 B 站直播间地址或房间号，点击“开始延时翻译”，打开独立播放器并启动播放与翻译。
翻译记录：滚动查看已完成的翻译，支持选择文字和复制。尚无记录时页面保持空白。
主窗口中央不再显示欢迎文字或快捷按钮。悬浮字幕采用紧凑的行间距，关闭日语原文后不预留原文空行。
标题栏可拖动，双击可最大化/还原；窗口边缘可调整大小。首次安装默认白色主题，升级保留已保存的黑白主题选择。
1. 完整解压整个压缩包，不要只取出 Kotoshiro.exe；engine 与 player 文件夹都要保留。双击 Kotoshiro.exe。
2. 点击“设置”，在“翻译服务”页选择翻译方式。
   “翻译上下文段数”默认3，可设置0～30。0表示只翻译当前段；其他值会带上最近N段成功的日语原文和中文译文。
   更多前文可能改善人称、术语和话题衔接，但每次请求输入量增加，可能变慢，API费用也可能增加；请求次数不因段数增加。本地语音识别的模型和计算方式保持不变。
   保存后从下一次开始翻译生效。实时与延时共用该选项；停止后重新开始、刷新直播时清空上下文，翻译记录不会自动作为全部上下文发送。
   术语表支持“导入 TXT”“导出 TXT”。导入合并到当前内容并按完整行去重，已有术语不被替换；同一原文的不同译法需要自行确认。
   导出仅包含当前术语文字，使用UTF-8，不包含账号、密钥、翻译历史或其他设置。导入或编辑后点击“保存设置”用于下一次翻译。
   新安装默认五条：ひのめ → 火羽、配信 → 直播、リスナー → 观众、切り抜き → 直播切片、アーカイブ → 直播回放。
   原先未修改的四条内置示例会更新为五条，已有自定义术语与手动清空内容保留；包内“术语表示例.txt”也为这五条。
   设置窗口为非模态：打开时主窗口仍可拖动、缩放与切换页面，重复点击设置会切回同一个设置窗口。编辑期间暂不启动翻译，保存或取消后恢复；关闭主窗口也会关闭设置窗口。
   使用订阅：选择“ChatGPT 订阅 · 账号登录”，点击 Continue with ChatGPT，在浏览器完成 OpenAI 官方登录和订阅额度授权。
   登录后程序获取该账号可用模型。选择模型，点击“测试订阅翻译”，会消耗少量订阅用量。无需填写 API 密钥。
   使用 API：选择平台，填入 API 密钥，再从“翻译模型”下拉框选择模型。
   支持 DeepSeek、OpenAI、Google Gemini、Anthropic Claude、自定义兼容服务。
   内置平台会预填地址与接口类型；DeepSeek 预设 deepseek-flash 和 deepseek-v4-pro。
   点击“获取模型”可读取该平台当前可用模型。此操作只读取模型信息，不发起翻译。
   OpenAI、Gemini、Claude、自定义服务也可获取兼容列表；部分服务不提供此接口。
   下拉框支持直接填写模型 ID；获取失败不会清空正在使用的模型。请选支持文字翻译的模型。
   原有 DeepSeek 地址、模型和密钥会保留；DeepSeek 初始模型为 deepseek-flash。
   切换平台时，会分别保留地址、模型和密钥；点击“保存设置”后才写入磁盘。
3. API 模式点击“测试连接”。订阅模式点击“测试订阅翻译”。这会翻译一句日语，使用对应服务的少量用量。
4. 切换到“语音识别”，在“识别方式”中选择“本地识别”或“API 识别”。
   本地识别：先点击“选择文件夹”，选择 D 盘等存放位置。
   模型不会默认下载到 C 盘。显卡组件及显卡缓存也保存在这个文件夹中。
   选择识别模型后，无 NVIDIA 显卡可点“下载所选模型”；有 NVIDIA 显卡可直接点“一键启用显卡”。
   程序自动下载所需组件和所选模型、校验文件，并验证实际显卡计算，无需手动安装 CUDA。
   Tiny：约 78 MB，适合低配置试跑，但容易听错。
   Base：约 148 MB，默认入门模型。
   Small：约 488 MB，本机日语样本测试准确，适合有一定性能的电脑或显卡。
   Turbo：约 1.62 GB，建议高配置或显卡加速时测试，CPU 可能处理较慢。
   API 识别：选择“OpenAI”或“自定义兼容 API”，分别填写识别 API 地址、识别模型和识别 API 密钥。
   OpenAI 默认地址 https://api.openai.com/v1，默认模型 whisper-1；也可从列表选择其他有权限使用的语音模型，或手动填写模型 ID。
   自定义服务需要兼容 OpenAI 的 audio/transcriptions 接口；可填写 HTTPS 基础地址或完整的 /audio/transcriptions 地址。
   选择“自定义兼容 API”后，模型框支持直接填写服务商提供的语音识别模型 ID，列表不再固定显示 OpenAI 预设。
   硅基流动示例：地址 https://api.siliconflow.cn/v1，模型 FunAudioLLM/SenseVoiceSmall，填入硅基流动的 API 密钥。
   程序按硅基流动官方字段上传 file/model，SenseVoice 自动识别语言；该模型支持日语。尚未使用真实密钥实测识别质量或耗时。
   DeepSeek 官方目前不提供音频转写，Flash / V4 Pro 是文字翻译模型。填入其官方地址用于识别时，会在上传音频前提示。
   普通 chat/completions、responses、messages 等文字翻译接口不能用来识别音频。模型与密钥需要支持所选语音识别服务。
   识别密钥与翻译密钥单独保存，不会自动互相使用。ChatGPT 订阅登录目前用于文字翻译，不能代替识别 API 密钥。
   API 识别系统声音不需要下载本地模型、启用显卡或选择文件夹；B站延迟播放器仍需要目录保存临时视频缓存。
   点击“用录音测试 API 识别”，最多上传所选日语录音前 30 秒。这是实际识别请求，会消耗语音 API 用量，并按该服务商的规则计费；测试只返回日语原文，不调用翻译。
5. 本地模式等模型准备完成；API 模式填好识别设置。点击“保存设置”，播放日语直播，选择直播正在使用的扬声器或耳机，再点击“开始翻译”。
6. 在“设置 → 外观与字幕 → 界面主题”选择“黑色”或“白色”。设置中会即时预览，点击“保存设置”后保留选择。
   此页也可选择是否显示日语原文，并修改中文字号和字幕不透明度。
7. 字幕窗口置顶显示，使用圆角、无标题栏样式，没有缩小和关闭按钮。
   完成的字幕按顺序显示为多行历史。最多保留最近 300 条，原文与译文合计最多 10 万字符，达到上限时移除最早内容。
   拖动右侧滑条或使用滚轮查看历史；离开底部后，新字幕不会打断当前阅读位置。滚回底部或右键“回到最新字幕”可恢复自动跟随。
   字幕内容可选择并复制。右键可复制全部历史、清空历史或隐藏字幕；按 Esc 也可隐藏。
   拖动顶部的小握柄或空白边缘移动窗口，拖动外边缘调整大小；点击文字会选择文字。
   主窗口“显示字幕 / 隐藏字幕”可重新打开或收起字幕。
   点击“停止翻译”后，字幕栏立即隐藏；停止时不清空历史，仍可点击“显示字幕”重新查看。启动中停止同样生效。
   主窗口的“鼠标穿透”可让你操作字幕后面的直播；需要滚动历史、复制文字、移动或缩放字幕时，请先关闭该选项。
   Ctrl + Alt + T 开始 / 停止。如果快捷键被占用，请用主窗口按钮。

B站链接与延迟播放器（0.6 新增）
先在主窗口设置翻译服务与语音识别方式，再选择左侧“延时翻译”。
本地识别需要准备好模型。API 识别不需要本地模型，但两种方式都需要选择可写目录保存视频缓存；尚未选择时会提示选择文件夹。
在左侧“延时翻译”输入 https://live.bilibili.com/22748536 这样的直播间链接，或直接输入房间号，再点击“开始延时翻译”。链接里的推广参数会忽略。
默认额外缓存 10 秒，范围 3～60 秒；点击“开始延时翻译”，软件打开独立播放器并自动获取直播源、启动翻译与播放。在播放器中仍可通过“打开直播”按钮开始或停止。
音频从提前收到的直播缓存中识别和翻译；画面和播放声音一起延后。此模式不采集系统输出设备，不会混入其他软件的声音。
字幕显示在视频里面，并按播放器时间选取。暂停时字幕不会跳到后面的直播内容；全屏时也会显示字幕。
默认勾选“字幕未准备好时等待”。识别或翻译较慢时，播放器会暂停等待并增加实际延迟；取消勾选后优先连续播放，字幕可能漏掉或迟到。
延迟值是本软件启动时的缓存目标，不是精确的直播端到端延迟。B站原有延迟、关键帧间隔、网络与播放器打开耗时会叠加。
字幕以一段识别音频为单位绑定时间，暂不提供逐字或逐句强制对齐。可在识别设置中调整最长分段。
暂停/继续：按钮或空格；全屏：按钮或 F；退出全屏：Esc。Ctrl + Alt + T 在播放器窗口打开时控制直播开始/停止。
0.9.3 全屏移除窗口外围的白色间隙。视频按原比例显示，原画面与显示器比例不同造成的黑色上下/左右留边仍会保留。
视频与评论区之间的居中箭头可收起/展开评论，普通窗口和全屏都可使用；隐藏评论不会退出账号、断开弹幕或清空已收到内容。
点击“刷新直播”可取消当前播放和识别、清理本次缓存、重新获取直播源并缓冲。全屏时可点击箭头上方的刷新图标，也可按 F5 / Ctrl+R。
刷新保留房间、清晰度选择、音量和评论区展开状态；需要重新缓冲，画面不会立即恢复。若直播已结束，会显示未开播提示。
开启“字幕未准备好时等待”时，起播缓存目标取用户延迟与“识别分段+2秒”的较大值，并等首段处理完成后播放。这会增加低延迟配置的实际起播等待，以减少按段暂停。
发生视频缓存或字幕不足时，至少准备好2秒余量再恢复；已经结束且全部处理完成的短尾段可正常播放完。取消字幕等待后不因译文未完成而暂停，字幕可能迟到。
状态区分别显示手动暂停、等待字幕、等待视频缓存和播放器缓冲。耗时区显示本段处理时间、字幕余量、硬件/软件解码及可用掉帧计数；不可用的计数显示 --。
播放器保留画面缓冲恢复余量，字幕文字仅变化时重新显示；后台仍按播放时间选择字幕。直播关键帧、接口耗时、网络与画质均会影响实际体验。
音量可在播放器窗口调整。先停止直播后再修改延迟或等待选项。
直播未开播、被锁定或需要额外授权时会提示；暂不支持付费或受限直播接入。
0.6.1 修复播放器无法读取 Windows 受信任根证书而导致 HTTPS 直播立即中断的问题。保持证书校验，不需要用户手动安装证书或修改设置。
临时网络错误及直播源 HTTP 429/5xx 会有限重试；重试仍失败、签名失效或直播结束时需重新打开。暂不自动切换 CDN 或重新取得直播源。错误提示会区分证书、HTTP 状态、超时和缓存写入问题。
主窗口的原有系统声音翻译方式仍然可用。
API 识别临时失败时，该段会显示“这一段识别未完成”，下一段继续处理；连续三段识别失败会停止。密钥无效、权限或余额错误会立即停止，请检查识别服务设置。程序不会自动重发失败的识别请求。
播放与翻译缓存位于“语音识别 → 文件存放位置”所选目录\.kotoshiro\player-cache\本次随机编号；已有 .tingyi 文件夹的模型目录继续复用旧路径。停止或关闭时清理本次目录，不删除模型。
播放落后缓存超过 2 分钟、磁盘剩余不足 512 MB 或翻译队列持续堆积时会停止并提示。
非正常断电或强制结束程序可能留下本次缓存。关闭软件后可在所选文件存放目录的 .kotoshiro\player-cache（旧目录为 .tingyi\player-cache）中检查这些目录。
当前提供普通公开直播源；具体能否打开和清晰度以 B站返回的地址为准。

B站弹幕、账号和清晰度（0.7 新增）
播放器右侧显示直播弹幕。打开直播后自动连接，可滚动查看评论；“跟随新弹幕”控制自动滚到底部。
弹幕按实时到达显示，视频仍有翻译延迟，因此弹幕可能提到尚未播放的内容。全屏时右侧弹幕区仍可使用。
弹幕连接独立于视频，暂时断线会自动重试，不会因为弹幕失败而停止视频。
点击右侧“登录B站”，用 B站手机客户端扫描软件生成的二维码，并在手机上确认。
程序通过 B站网页登录接口取得本次扫码会话，并验证账号 UID。不需要密码，也不会读取浏览器或其他应用的登录 Cookie。
登录成功后，右侧显示账号名；在输入框输入文字，点击“发送”或按 Enter 发弹幕。
软件不会自动发弹幕。内容长度、发送频率、账号权限、禁言和审核要求以 B站返回结果为准。
发送失败会保留输入文字；网络超时或停止时结果可能未确认，请先查看弹幕区再决定是否重发。
点击“切换账号”可重新扫码；“退出”只删除言代Kotoshiro保存的这次登录，不会退出浏览器或手机上的账号。
新用户本机登录文件为 %LOCALAPPDATA%\Kotoshiro\bilibili.dat，使用 Windows 当前用户 DPAPI 加密，不随安装包分发。旧用户兼容路径见“数据与费用”。
每台电脑单独扫码。会话过期或 B站要求重新验证时，需要再次登录。
清晰度默认“自动”。粘贴房间链接后点“读取清晰度”，下拉框将显示该房间提供的 AVC 画质档位。
播放过程中选择另一档，再点“应用清晰度”，软件会停止旧取流、清理旧缓存，然后重新缓冲并播放。
界面显示实际返回的画质；B站可能对未登录账号或没有对应权限的账号返回较低档位。登录后可重新读取/应用。
清晰度档位不代表固定分辨率，画面尺寸和码率仍由直播源决定。尚不支持单独选择 HEVC/AV1 编码。
B站网页接口或弹幕协议变化时可能需要更新软件。

选择不同翻译 API
DeepSeek：地址 https://api.deepseek.com，接口选择 OpenAI 兼容 / Chat Completions。
OpenAI：地址 https://api.openai.com/v1，默认接口 OpenAI Responses；也可选择 Chat Completions。
Google Gemini：地址 https://generativelanguage.googleapis.com/v1beta/openai，使用 Google 官方的 OpenAI 兼容接口与 Gemini API 密钥。
Anthropic Claude：地址 https://api.anthropic.com/v1，接口 Anthropic Messages，使用 Claude API 密钥。
自定义 API：填写服务商提供的 HTTPS 基础地址、模型、密钥，选择相应接口类型。
接口地址既可填基础地址，也可填与所选类型一致的完整请求地址，程序不会重复追加后缀。
例如基础地址 https://example.com/v1 或完整地址 https://example.com/v1/chat/completions。
密钥与模型权限必须属于所选平台；网站账号密码不能填写到 API 密钥栏。
当前支持上述三种接口结构，不保证所有供应商特有的签名或额外参数都可用。
不同模型的推理与响应速度由服务商决定。程序仅向 DeepSeek 官方接口发送关闭思考的专用参数，不会把它发给其他平台。

ChatGPT 订阅模式
已加入官方 Sign in with ChatGPT，面向本地运行的应用。实际账号资格、工作区权限与可用模型以授权结果为准。
密码只在浏览器中的 OpenAI 官方页面输入。软件不会读取 ChatGPT 网页 Cookie，也不会读取 Codex 的已有登录凭证。
每台电脑分别登录。账号凭证在本机使用 Windows 当前用户加密，自动续期，不随软件或源码分发。
登录后只有明确授予 chatgpt.tokens.use.direct 权限才能翻译；仅登录身份不代表订阅授权成功。
可选择已保存账号、重新授权、添加账号、刷新模型或退出登录。相同邮箱的不同注册以短编号区分。
账号切换不会退出其他账号。登录和退出立即生效，关闭设置不会撤销；选用的账号与模型在保存设置后生效。
主窗口会显示使用的账号与订阅模型。新账号首次授权成功会提示“正在使用 ChatGPT 订阅”。
“管理订阅用量”打开 https://chatgpt.com/settings/usage，可查看和管理授权、应用限额与信用额度设置。
达到订阅或应用限额会停止翻译，提示检查用量；软件不会自动切换到付费 API，也不会在此软件里开启额外信用额度消费。
官方订阅限额和用户在 ChatGPT 设置中开启的信用额度规则仍适用，不代表无限免费翻译。
退出时尝试撤销服务器的可续期授权，再清除本机凭证。网络或服务器失败会有限重试，未确认服务器撤销会明确提示。
凭证被撤销或刷新失效时需要重新登录；临时服务器失败会保留登录信息。
订阅模式只向官方 https://api.openai.com/v1/responses 发送文字，使用官方要求的流式返回，收到完成事件后才显示正式译文。
遇到中途额度错误、不完整回复或断网，已收到的半句不会被当作成功译文。
“OpenAI”选项仍是独立的 API 密钥模式；使用订阅请选“ChatGPT 订阅 · 账号登录”。
官方说明：https://developers.openai.com/siwc/quickstart
本地应用接入：https://developers.openai.com/siwc/token-sharing-open-source

多电脑使用
软件自带 .NET 运行环境与 CPU 识别引擎，不需要安装 Python 或 .NET。
密钥使用 Windows 当前用户的 DPAPI 加密。复制软件到另一台电脑后，应在该电脑上重新填入密钥。
每台电脑分别填写自己的识别与翻译 API 设置，或登录自己的 ChatGPT 账号。本地模式另需选择并准备模型文件夹。
用“语音识别”页本地模式的“用日语录音测试识别”测试该机器实际速度。
若本地识别耗时接近或超过音频时长，可换较小模型、点击“一键启用显卡”，或改用 API 识别。
API 模式的识别速度取决于网络与服务商。识别 API 与翻译 API 可以来自不同平台，分别使用对应模型、密钥和额度。
默认线程数按本机逻辑核心数设置，最多 8，可在设置中修改。
部分老旧 CPU 可能不支持本地引擎发行版所需的指令集，此时可尝试 API 识别；尚未验证所有老旧电脑。
若本地引擎无法启动，先检查压缩包是否完整；也可能缺少 Microsoft Visual C++ x64 运行库。
微软官方下载：https://aka.ms/vs/17/release/vc_redist.x64.exe

首次下载的显卡组件约 436 MiB（约 457 MB），展开后约 700 MB；另外需要模型空间。

改变模型存放位置
在“语音识别”页点击“选择文件夹”，选好后保存设置。
如果原位置已有下载的模型，选择新位置后点击“迁移现有模型”。
迁移会先复制并校验，保存新位置，再删除原位置中对应模型；取消或文件冲突会保留原模型。
继续沿用旧数据目录时，会检查旧版 %LOCALAPPDATA%\TingyiLive\models 目录；已保存的自选模型路径保持原样，不因更名而重新下载模型。
迁移只处理软件支持的模型文件，不删除原目录中的其他文件。
显卡组件不随此按钮迁移；更换目录后可在新目录点击“一键启用显卡”重新准备。

声音与字幕
程序采集所选输出设备的全部声音。因此同一设备上的通知、其他视频或通话也可能被识别。
这一版没有按浏览器进程隔离声音。最好让其他软件保持安静，或者使用独立输出设备。
没有声音时检查输出设备选择和 Windows 音量；戴耳机不影响采集。
分段最长默认 6 秒，检测到静音会提前提交；这是静音检测，不是完整的语音与音乐分类。
字幕延迟包括等待断句、排队、所选方式的语音识别、网络和文字翻译时间；API 识别另包含音频上传与识别服务等待。
主窗口逐段显示：采集段、排队、识别、翻译、字幕更新，以及本段起点到更新的估计时间。
“采集段”包含讲话本身与断句等待，不代表每句话结尾后的纯等待。
“字幕更新”测量 UI 调度和控件更新，不包含屏幕实际绘制。
识别服务准备时间只在开始翻译时测量，与每段识别耗时分开。本地模式包含模型加载，API 模式不加载本地模型。
在“语音识别”页本地模式点“用录音测试识别与翻译耗时”，可测试所选日语文件前 30 秒，包含一次真实文字翻译用量。
API 模式的“用录音测试 API 识别”最多处理所选录音前 30 秒，会消耗实际语音识别用量，并按服务商规则计费；结果框中的识别耗时包含上传、服务等待和读取结果。
录音测试不会播放音频，按音频时钟模拟分段；与实际直播中的排队和背景音乐情况可能不同。
连续讲话或背景音乐一直存在时，会等到“最长分段”后提交；需要更快反馈可尝试改成 3 秒。
较短分段可能拆开长句，也会增加 API 请求次数。此版本不会自动修改你已保存的分段设置。
持续长句可能被分段，游戏音效、音乐、多人抢话、专有名词可能造成错误。
队列最多保留最近两段，旧音频超过 15 秒会跳过，以防延迟无限累积；因此慢电脑可能漏句。
译文使用最近三句上下文与用户术语表；只翻译稳定分段，不逐字更新。

数据与费用
本地识别：音频由本机仅绑定 127.0.0.1 的识别进程处理，不发送给语音识别 API。
API 识别：短音频片段以 WAV 文件发送给你填写的 HTTPS 语音识别服务，由该服务返回日语原文。
文字翻译服务收到当前日语文字、最近三句日语与中文、术语表；它不会收到软件发送给识别服务的音频。
识别 API 的数据处理与保留规则由所选服务商决定。
主窗口与字幕历史只保留在本次运行中，退出软件后不保存；隐藏字幕窗口不会清空当前历史。
识别 API 密钥和翻译 API 密钥分别保存在本机加密设置中，不能随软件分发；程序没有内置任何密钥。
本地识别不收识别接口费用；API 识别与 API 文字翻译各自消耗用量，并按各自服务商规则计费。翻译若使用订阅模式，则使用官方授权的 ChatGPT 额度。
录音测试也会调用实际选用的服务：API 识别测试最多发送前 30 秒，消耗识别用量；本地识别与翻译耗时测试会消耗文字翻译用量。
新用户的小型设置文件与加密密钥保存在：%LOCALAPPDATA%\Kotoshiro\settings.json
从旧版升级时，若新 Kotoshiro 数据目录不存在而旧 %LOCALAPPDATA%\TingyiLive 目录存在，会继续使用旧目录内的设置与账号，不移动或删除旧数据；若新数据目录已存在则使用新目录。
ChatGPT 注册信息与登录凭证保存在同目录的 chatgpt.dat，整份文件使用 DPAPI 加密。请勿把本机账号数据随软件分发。
大型模型、显卡组件、CUDA 缓存保存在用户选择的模型文件夹。
软件运行环境仍可能在系统临时目录展开文件；“选择模型文件夹”控制的是模型和显卡组件。
