言代Kotoshiro 0.9.10 界面设计参考

本版主要参考：用户提供的 ChatGPT 桌面应用窗口截图。
程序图标采用用户提供的dui-icon.ico，保持原始图像字节，内含16/24/32/48/64/128/256像素版本，用于Windows程序、任务栏与窗口。
顶部标志采用同一素材目录内已有的dui-mark-black.png/dui-mark-white.png透明纯线条版，不重新绘制。运行时去掉透明外边距，保留两像素安全留边，按原比例居中绘制到文字后的20像素槽内，没有方形底板。
翻译服务页提供跨平台共用的上下文段数和术语表TXT导入/导出，使用五条默认术语，保留固定底部保存/取消。
设置窗口使用非模态单实例，打开时不禁用主窗口拖动和缩放。
采用左侧浅灰导航、中央白色字幕阅读区、细分隔线、底部圆角声音操作区与紧凑标题栏。
左侧主分类为实时翻译、延时翻译、翻译记录；实时/延时页面清除欢迎文字与快捷按钮，翻译记录只在记录页显示。
原生非客户区绘制关闭，自定义标题栏之外不再额外绘制系统标题条。字幕收紧段距，纯中文不保留日语占位。
黑白主题统一使用中性色；白色主题主要按钮为黑底白字，黑色主题为白底黑字。蓝色用于链接与状态提示。
设置窗口沿用左侧导航与右侧内容结构，保存/取消固定在内容区底部。主窗口与设置窗口支持标题栏拖动、最大化和边缘缩放。
没有使用 ChatGPT 的名称、标志或其他品牌资产作为软件品牌。

Microsoft Fluent 2 — Layout
https://fluent2.microsoft.design/layout
采用统一间距与邻近分组，区分声音输入、操作、翻译记录和状态信息。

Linear — Behind the latest design refresh
https://linear.app/now/behind-the-latest-design-refresh
参考中性深色背景、克制的边框与清晰的信息层次。

设计实现：原生 WinForms 控件配合自行绘制的圆角卡片、按钮和声音电平条。
字幕独立采用圆角无标题栏窗体。黑白两种主题保留，色彩与本版桌面窗口统一。
悬浮字幕改用多行历史与右侧原生滚动条，顶部握柄用于移动窗口。
参考页面用于布局思路，没有使用其图片或品牌资产。

DeepSeek 模型 ID 与模型列表协议
https://api-docs.deepseek.com/api/list-models/
0.8 的 DeepSeek 预设：deepseek-flash、deepseek-v4-pro。
其他平台的模型列表按用户填写的 API 地址与密钥获取。

语音 API 的请求结构参考 OpenAI 官方语音转写文档
https://developers.openai.com/api/docs/guides/speech-to-text
使用 audio/transcriptions 接口，把日语音频识别为日语文字，再交给独立的翻译服务。
